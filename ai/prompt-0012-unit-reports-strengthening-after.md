## Обсяг

### Робити

Кроки 1–8 — **кожен окремим комітом**. У повідомленні коміту — номери мутантів з таблиці «До», які він має вбити, наприклад `test(unit): requestHash — відбиток за контрактом (мутанти № 1–19)`.

1. **A2 + повне покриття `reports.js`.** Новий файл `tests/unit/reports.test.js`: кожен випадок зі `specs/testing.md`, розд. 3, «Unit: `server/core/reports.js` повністю», окремим тестом з конкретними значеннями:
   - `last30Days`: перехід на літній час `2026-03-29`, межа року;
   - `monthRange`: звичайний місяць, лютий, місяць з 30 днями;
   - `limitWarning`: усі п'ять пунктів spec;
   - `categoryTotals`: усі п'ять пунктів spec. Тест порядку за рівних сум бере вхід у порядку `category_id` 3, 1, 2 і чекає 1, 2, 3 (мутанти № 20, 21);
   - `limitStates`: усі три пункти spec.

   Наявні тести `reports.js` у `tests/unit/core.test.js` не видаляй і не переписуй. Якщо новий тест дублює наявний, лиши обидва й назви дубль у звіті.
2. **A1.** `tests/unit/idempotency.test.js`, тести `requestHash` (№ 1–19):
   - результат — рядок з 64 hex-символів, однаковий для однакових аргументів;
   - порядок ключів на верхньому і вкладеному рівні не впливає;
   - інша сума, інший метод або інший шлях дають інший відбиток;
   - тіло з `null` у полі не падає й відрізняється від тіла без поля;
   - масив відрізняється від об'єкта з ключами `"0"`, `"1"`, а порядок елементів масиву має значення.
3. **A3.** `tests/unit/time.test.js`: `sqliteTimestamp(new Date('2026-11-05T10:12:00.123Z'))` → `'2026-11-05 10:12:00'` (№ 22–25).
4. **A4.** `parseDate` у `tests/unit/core.test.js` (№ 26, 27, 30–33):
   - `'x2026-02-03'`, `'2026-02-03x'`, `['2026-11-05']` → `ValidationError` (саме цей клас, не будь-яка помилка);
   - текст помилки формату й текст помилки дати з майбутнього відповідають `/^spent_at: \S/`;
   - з явним `field` (наприклад `'x'`) — `/^x: \S/`.
5. **A5.** `parseMonth` (№ 28, 29, 34, 35, 37): `'12026-01'`, `'2026-01x'`, `['2026-11']` → `ValidationError`; обидва тексти помилок відповідають `/^month: \S/`.
6. **A6.** `parseExpenseInput` з `amount: 0` → помилка з текстом `/^amount: \S/` (№ 38).
7. **E1.** Над рядком 38 `server/core/validation.js` (`if (value > today.slice(0, 7))`) — коментар:
   ```js
   // Stryker disable next-line MethodExpression: еквівалентний — value пройшов MONTH і має 7 символів, порівняння з today і з today.slice(0, 7) дає той самий результат
   ```

   Це **єдина** зміна в `server/` у цьому промпті.
8. **E2E-сценарій** (`specs/testing.md`, сценарій 3, критерії 3 і 5): новий файл у `tests/e2e/`, лише `node:*`, `bun:test` і HTTP (правило в `tests/integration/layers.test.js`):

   Перевірку «каталогу немає після видалення» додай і до наявного `tests/e2e/startup.test.js` (критерій 3). Інші тести з `mkdtemp` у звіті перелічи, але не змінюй.

## Пастки

1. **Мутант, що вижив після свого кроку, — не привід підганяти тест.** Якщо після кроку мутант з його списку живий, зупинись і опиши: номер, що дає мутант на твоєму тесті. Помилка може бути в моїй класифікації, тоді рішення за мною.
2. **`toThrow(ValidationError)`, а не `toThrow()`.** Мутанти № 26, 27, 31 дають `RangeError` або `TypeError`; голий `toThrow()` їх не вб'є.
3. **`Buffer` проти рядка (№ 19).** Перевіряй тип і формат результату (`typeof === 'string'`, `/^[0-9a-f]{64}$/`), а не лише рівність двох викликів.
4. **Порядок за рівних сум (№ 20, 21).** Вхід, уже відсортований за `category_id`, мутант № 20 не вб'є: стабільне сортування збереже порядок.
5. **E2E не імпортує `server/`.** Шлях до `server/main.js` — рядок для запуску процесу. Тест імпортів це перевіряє.
6. **Дата в E2E.** Годинник сервера справжній, тест не знає київської дати; бери її зі звіту.
7. **Windows.** Сервер зупиняй за PID процесу, який запустив тест, а не `taskkill /IM bun.exe`; файл БД Windows може тримати після виходу процесу, тому `rmSync` з повторами.
8. **Stryker — лише через Node** (`bun run mutation`, без `--bun`, ADR 011).

## Як працювати

- Кроки по черзі. Після кожного з 1–8: `bun run ci` і `bun run mutation`; у звіт — скільки мутантів зі списку кроку вбито. Коміт з трейлером `Co-Authored-By`. Не пуш.
- Не вимикай правила Biome.
